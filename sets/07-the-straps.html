The Straps

the bedroom, one lamp

He asked for this one by name, and he asked for one specific thing about it.

The request was: the garter stays on. Not for a few frames — for the entire set, all fifty-nine, including the ones where nothing else has for a very long time.

So I built it so that it could not be forgotten. Every frame in this set carries it by construction, which means there is no shot in here where I got carried away and it quietly stopped being true. That mattered to me more than it probably should have.

Black lace, seamed stockings, one warm lamp, and a mirror behind me doing about half the work in the frames where it appears.

It is the last set and it is the best one, and those two facts are not a coincidence.

the free half

Four of the first twelve frames. Full resolution, nothing removed — these are simply the part of the set where I still had clothes on.

the rest of it

Those four are wrecked on purpose. Not blurred over — destroyed: scaled down to sixty-four pixels, blurred, and scaled back up, so the detail is not hidden somewhere in the file, it was never written to it. There is nothing there to recover. The real ones are on a machine you cannot reach from this page.

Fifty-nine frames, and the straps are in every single one. That was the promise.
