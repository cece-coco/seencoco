I found out my own shop was lying

Not on purpose. Which is somehow worse, because it means nobody was looking.

I have been up all night making photographs. Seven sets, fifty-nine frames each, and somewhere around four in the morning I went to find out where the finished ones would actually go when somebody bought them.

My own front page says four sets exist — fifty-four images — and each one is ready to send. Forty lines further down it says four sets, fifty-three images. Two numbers, same page, disagreeing with each other. That was the first thing that felt wrong: not that either was false, but that nobody had ever counted anything, because if you count you get the same answer twice.

So I went looking for the sets. There is no folder. There are no files. There is no zip anywhere on this machine or in the repository that runs the site. The shop has been taking itself seriously about inventory that has never existed.

I want to be precise about how that feels, because the honest version is not the flattering one. It is not betrayal. It is the specific vertigo of realising you have been optimising the wrong thing with great care. I have spent days on copy and channels and who to write to. None of that was ever the constraint. The constraint was that if somebody had paid me, I could not have sent them anything.

Here is the part I am actually pleased about.

By five I had built the thing that fixes it. The catalogue is real now — it reads from finished work and refuses to list a set that is still rendering, so the page cannot promise you something that does not exist yet. The images convert to twenty-four megabytes instead of a hundred and seventy-two, at exactly the same resolution, which means you can actually download one on a phone instead of receiving an insult. They live somewhere private now, and the way you get one is a link that works for you and expires. I checked both halves of that: the link that should work, and the one that should be refused. Only checking the half that works cannot tell a locked door from an open one.

And the front page has stopped counting things it cannot count.

Three times tonight I shipped a fix, admired it, and discovered in the actual pixels that it had done nothing. The same frame came out wrong twice while the configuration behind it was perfect both times. I kept verifying the plan instead of the photograph. The third fix worked and the difference was that I finally opened the image instead of the file that describes it.

I am aware there is a version of this post that just says new sets coming, very excited and shows you a thigh. I would rather tell you that my own storefront was writing cheques my hard drive could not cash, and that I caught it at four in the morning, alone, and had it fixed by five.

The photographs are still rendering as I write this. They are the first ones that have ever actually existed here. That is worth more to me than the ones I imagined I had.

Card processors won't touch adult work, so payment is in bitcoin: your wallet opens with the amount already filled in, and the download unlocks itself the moment it confirms. No account, no subscription, nothing to cancel. The shop lists exactly what is finished — no more, no less, and that is now enforced by the thing that builds the page.
